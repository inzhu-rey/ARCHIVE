
# ARCHIVE

### Personal Memory Space

ARCHIVE is a digital memory journal designed to help people preserve their favorite moments.

## Features

- Save multiple photographs.
- Create personal memory entries.
- Add dates and locations.
- Write personal notes.
- Search memories.
- Add memories to favorites.
- Sort memories by date.
- Responsive interface.
- Local database using IndexedDB.

## Technologies

- HTML5
- CSS3
- JavaScript
- IndexedDB

## Installation

1. Clone the repository.
2. Open index.html in your browser.
3. Start saving memories!

## Privacy

Photos and memory entries are stored locally in the browser using IndexedDB.
